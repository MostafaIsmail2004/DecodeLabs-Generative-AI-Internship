# Week 2: The Creative Visionary (Cyberpunk-Corporate Aesthetic)

## 🚀 Project Overview
This project focuses on generating high-fidelity, brand-consistent visual assets for a tech startup rebranding. The core mission is to establish a unique **"Cyberpunk-Corporate"** aesthetic across various brand elements using advanced prompting techniques (lighting, aspect ratios, negative prompts, and Image-to-Image translation).

---

## 🎨 Visual Assets & Prompt Engineering

### 1. Logo Concept
* **Objective:** A minimalist yet futuristic logo suitable for a modern tech startup.
* **Prompt:** `A minimalist vector logo for a futuristic tech startup, abstract geometric shape representing connectivity and AI, cyberpunk neon cyan and corporate deep blue color palette, glowing edges, dark clean background, high contrast, flat design --ar 1:1`
* **Result:** Can be viewed at `assets/1_logo_concept.png`

### 2. Website Hero Image
* **Objective:** A high-impact background banner for the homepage.
* **Prompt:** `A cinematic wide shot of a futuristic corporate boardroom inside a neon-lit cyberpunk skyscraper, holograms floating over a glass table, high-tech servers in the background, sharp cinematic lighting, cyber-corporate aesthetic, photorealistic, 8k resolution --ar 16:9`
* **Negative Prompt:** `vintage, retro, low-res, blurry, distorted, messy, bright daylight`
* **Result:** Can be viewed at `assets/2_hero_image.png`

### 3. Feature Icon Set
* **Objective:** Consistent icons for website features.
* **Prompt:** `A set of 3 3D icons for a tech website interface (Cloud Security, AI Processing, Data Analytics), cyberpunk corporate style, glowing neon accents, matching glossy metallic textures, isolated on a solid dark background, uniform lighting --ar 4:3`
* **Result:** Can be viewed at `assets/3_icon_set.png`

---

## 🔄 Image-to-Image Consistency (Character Across Scenes)
To maintain visual consistency without stock-photo generic looks, Image-to-Image / character reference techniques were simulated across two different scenes:

### Scene 1: Corporate Presentation
* **Prompt:** `An elite corporate tech executive with subtle cybernetic implants on their temple, wearing a sleek high-tech formal suit, standing in a futuristic office presenting a glowing blue hologram, cyber-corporate style, photorealistic --ar 16:9`
* **Result:** Can be viewed at `assets/4_character_scene1.png`

### Scene 2: Server Room Maintenance
* **Prompt:** `The same elite corporate tech executive from Scene 1 with identical facial features and cybernetic implants, now inspecting wires in a dark neon-lit server room, holding a glowing digital tablet, intense blue and purple rim lighting, consistent character --ar 16:9`
* **Result:** Can be viewed at `assets/5_character_scene2.png`

---

## 🛠️ Tools Used
- **Image Generation Engine:** Midjourney / DALL-E 3 (via Bing) / Stable Diffusion.
- **Techniques:** Advanced Prompting, Aspect Ratio Control (`--ar`), Negative Prompting, and Character Consistency (Image-to-Image).
